# 食品DB拡張用プロンプト（外部LLM向け）

`foods-db.js` に新しい食品データを追加してもらうためのプロンプトです。ChatGPT / Claude / Gemini など、どのLLMでも使えます。

## 使い方

1. 下記プロンプトの `{{ここに追加してほしい食品カテゴリや品目を書く}}` を埋める
2. `foods-db.js` の中身（全文、または `grep -o "name:'[^']*'" foods-db.js` で作った食品名一覧）を貼り付けて重複を避ける
3. LLMの出力を新しいファイル（例: `/tmp/new-foods.js`）に保存
4. `node scripts/validate-food-db.js /tmp/new-foods.js` で検証
5. 問題なければ `foods-db.js` の `];` の直前に貼り付ける

---

## プロンプト本文

```
あなたに、日本語の栄養管理アプリで使う食品データベースの拡張を手伝ってほしいです。

【出力形式】
JavaScriptのオブジェクトリテラルを1食品1行で、配列としてまとめて出力してください。
既存データと完全に同じ形式に従ってください：

{name:'食品名',yomi:'ヨミガナ（カタカナ）',tags:'検索用キーワード（ひらがな・別名などスペース区切り）',en:'english name',cal:100gあたりのkcal,p:タンパク質g,f:脂質g,c:炭水化物g,per:基準量g（通常100、既製品は1個/1パックの実量でも可）,fiber:食物繊維g,iron:鉄mg,calcium:カルシウムmg,vitc:ビタミンCmg,vitd:ビタミンDμg,salt:食塩相当量g}

【追加ルール】
1. 脂質が0.5g/100g以上の食品には、必ず fa（脂肪酸比率）を追加してください：
   fa:{sat:飽和脂肪酸比率,mufa:一価不飽和比率,n3:オメガ3比率,n6:オメガ6比率,trans:トランス脂肪酸比率}
   （比率の合計はだいたい0.8〜1.0程度になるようにしてください。0や1.0を大きく外れる値は避けてください）

2. タンパク質が1g/100g以上の食品には、必ず aa（アミノ酸プロファイル）を追加してください：
   aa:{leu:ロイシン比率,ile:イソロイシン比率,val:バリン比率,lys:リジン比率,met:メチオニン比率,thr:トレオニン比率,trp:トリプトファン比率,his:ヒスチジン比率,score:アミノ酸スコア(DIAAS近似値、0〜1.3程度)}
   （各比率は「gアミノ酸/gタンパク質」。動物性食品はscore 0.9〜1.3程度、精製穀物は0.4〜0.6程度、豆類・全粒穀物は0.6〜0.9程度が目安です）

3. よく使う1食分の目安量がある場合は serving:グラム数 を追加してください（省略可）

4. 栄養価は日本食品標準成分表（八訂）またはそれに準ずる信頼できるデータに基づいてください。
   根拠のない推測値は避け、不確かな場合は近い食品カテゴリの一般的な値を参考にしてください。

5. 【重複禁止】以下は既にデータベースに存在する食品名です。同じ名前・実質的に同じ食品の重複登録はしないでください：
   {{ここに既存の食品名一覧を貼り付ける（またはfoods-db.js全文）}}

6. 出力は配列 [ {...}, {...}, ... ] の形のみとし、説明文やMarkdownのコードブロック記法は付けないでください。

【追加してほしい食品】
{{ここに追加してほしい食品カテゴリや品目を書く（例：「日本の郷土料理20品目」「離乳食に使われる食品30品目」など）}}

一度に20〜40品目程度でお願いします（多すぎると精度が下がるため）。
```

## 補足

- 一度に大量発注すると個々のデータの精度が落ちやすいため、20〜40品目ずつに分けて依頼するのがおすすめです
- LLMによって脂肪酸・アミノ酸プロファイルの精度にはばらつきがあります。既存データ（例えば同じカテゴリの食品）と見比べて明らかにおかしい値がないか、`scripts/validate-food-db.js` の警告に加えて目視でも確認してください
